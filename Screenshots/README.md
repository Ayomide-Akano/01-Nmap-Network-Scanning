# Nmap Scanning Evidence

This directory contains screenshots captured during the practical Nmap scanning scenarios performed in the authorized laboratory environment.

The screenshots provide visual evidence of commands executed, scan results, service enumeration, filtering behavior, NSE enumeration, scan optimization, and output generation.

---

## Screenshot Organization

The screenshots are organized according to the practical scanning scenarios in which they were captured.

### Scenario 01 — Host Discovery and Network Mapping

Contains evidence related to:

- Host discovery
- Network mapping
- TCP port discovery
- Service and version detection
- Operating system detection
- Initial target enumeration

---

### Scenario 02 — TCP and UDP Port Scanning

Contains evidence related to:

- TCP SYN scanning
- TCP Connect scanning
- FIN scanning
- NULL scanning
- Xmas scanning
- Full TCP port scanning
- UDP scanning
- Targeted UDP scanning
- Combined TCP and UDP scanning
- UDP service detection

---

### Scenario 03 — Firewall Evasion and Filtering

Contains evidence related to:

- ACK scanning
- FIN, NULL, and Xmas scans
- Packet fragmentation
- Custom MTU
- Decoy scanning
- Source-port manipulation
- Invalid checksum testing
- MAC address spoofing
- Baseline comparison

---

### Scenario 04 — Scan Optimization and Output Formats

Contains evidence related to:

- Timing templates
- Scan delays
- Retry and timeout configuration
- Packet rate control
- Verbose scanning
- Reason reporting
- Normal output
- XML output
- Grepable output

### Scenario 05 — NSE Service Enumeration

- FTP
- SMB

The screenshots demonstrate how Nmap NSE scripts were used to gather additional service and configuration information.

## Scenario 06 — Comprehensive Security Assessment

No separate Scenario 06 screenshot directory is included.

Scenario 06 is the capstone security assessment that consolidates evidence and findings generated during Scenarios 01–05. It does not represent a separate lab execution with a new set of commands.

The assessment therefore uses the existing evidence from the previous scenarios rather than creating additional screenshots that could imply a separate assessment session.

---

## Evidence Integrity

The screenshots represent activities performed within an authorized virtualized laboratory environment using Metasploitable 2 as the target.

They are included as supporting evidence for the practical work documented in this portfolio.

The screenshots should be interpreted together with the corresponding commands, scan results, practical scenarios, and case studies rather than as standalone proof of vulnerability or exploitability.
