# Networking Concepts

This directory contains explanations of the networking concepts that make Nmap scanning techniques possible.

Understanding these concepts helps explain how Nmap identifies hosts, detects operating systems, discovers services, and interprets network responses.

Topics include:

- TCP Three-Way Handshake
- TCP Flags
- TCP Initial Sequence Numbers (ISN)
- TCP Window Size
- TCP Options
- Time To Live (TTL)
- IP Identification (IP ID)
- ICMP Messages
- TCP Reset (RST)
